# Shared phext test vectors

Each `NAME.phext` is a raw input stream; `NAME.expected.json` lists its non-empty scrolls in stream order:

```json
[{"coord": "1.1.1/1.1.1/1.1.1", "text": "..."}]
```

The expected files are generated by `cargo run -p phext-stream --example gen_vectors`, and
`cargo test -p phext-stream` checks every input against libphext 0.3.1, so the JSON is the Rust reference
behavior. Any implementation, in any language, should match all of them.

## Checking other implementations

From the repo root, with sibling checkouts in `../libphext-py`, `../libphext.node`, `../libphext-cs` (paths are
overridable):

```bash
python core/test-vectors/check_python.py [path/to/libphext-py]
```

```bash
node core/test-vectors/check_node.mjs [path/to/libphext.js]
```

```bash
dotnet run --project core/test-vectors/check-cs -- core/test-vectors
```
